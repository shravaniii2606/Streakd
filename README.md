# 🔥 Streak Tracker Web App

A productivity web app built using **Flask**, **SQLite**, **HTML**, **CSS**, and **JavaScript**  
to track daily tasks, maintain streaks, and earn XP for consistency.

## 🚀 Features
- Add daily tasks
- Track weekly & monthly progress
- XP system for completed tasks
- Streak counter
- Clean, Gen-Z inspired UI

## 🛠 Tech Stack
- Backend: Flask (Python)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite

## ▶️ Run Locally
```bash
pip install -r requirements.txt
python app.py
